# 90s BMW System Design Pack

Figma Make의 **90s BMW Design System**을 Universal Experience System에서 재사용할 수 있는 Markdown Design Pack으로 변환한 패키지다.

- Canonical contract: [`90s-bmw-system.md`](./90s-bmw-system.md)
- Local preview: [`preview.html`](./preview.html)
- Visual source: [Figma Make — 90s BMW Design System](https://www.figma.com/make/X5ajlclkcJOOEJ7VNwsdld/90s-BMW-Design-System?t=Q3m1RSRQGFq8a9rJ-1)
- Pack ID: `pack:90s-bmw-system`
- Pack version: `0.1.0`
- Status: `experimental`

이 팩은 색상 테마가 아니라 **90년대 독일 정밀 공학, 계기판, 기술 문서, 기업 모터스포츠**의 시각 문법을 정의한다. Product Binding과 UX Preset이 의미·상태·검증·회복을 소유하며, 이 팩은 그 의미를 어떤 위계·밀도·타입·표면·데이터 표현으로 드러낼지를 소유한다.

## Use

1. Product Binding과 UX Preset을 먼저 확정한다.
2. [`90s-bmw-system.md`](./90s-bmw-system.md)의 Capability Matrix에서 필요한 의미 표현을 확인한다.
3. 목표 매체의 Projection recipe를 적용한다.
4. `Unresolved` 항목은 추측하지 말고 Composition Manifest에 adapter decision 또는 gap으로 기록한다.

## Naming and trademark boundary

`90s BMW`는 원본 Figma 팩과 그 영감의 출처를 식별하기 위한 연구용 이름이다. 이 패키지는 BMW AG의 공식 디자인 시스템이 아니며 BMW 상표, 라운델, 모델명, 차량 사진의 사용 권리를 부여하지 않는다. 비-BMW 프로젝트에서는 팩의 표현 문법을 사용하되 상표 자산은 제거하고, 외부 공개 이름은 `90s German Precision` 같은 비상표 이름으로 투영한다.
