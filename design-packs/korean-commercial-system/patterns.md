# Korean Commercial — Composition patterns

> 정본 참조: [korean-commercial-system.md](korean-commercial-system.md) §§1 and 4.

## Hero split canvas

```text
warm hanji reading field (58%) | direct red geometry / bojagi field (42%)
serif headline + body           | bounded illustration / structural patchwork
------------------------------- five-color strip (6px)
```

At narrow widths, stack the reading field before the red field. The split expresses information hierarchy, not a background image treatment.

## Hanji form flow

| Region | Required rule |
| --- | --- |
| Context | thin dark header and numbered mono section code |
| Field group | sharp border, visible label, concise hint before failure |
| Error | field-local text + icon + color; preserve entered content |
| Commit | direct red primary action, only one in the local decision group |
| Result | durable confirmation/edit route; no toast-only completion |

## Status surface

Use a quiet warm field, hairline boundary, state text, explanation, timestamp/source when relevant, and a clearly named next action. Gold, red, blue, or green may reinforce state but cannot replace its text.

## Data / editorial surface

Combine serif only for section-level voice, Noto Sans KR for readable content, and mono labels for data. Preserve enough neutral canvas around direct pigment blocks; do not turn every region into a colored card.

## Cultural integrity check

- The product has a legitimate Korean cultural/heritage relationship or owner approval.
- Motif choice has a stated structural role (split, boundary, hierarchy), not a decorative excuse.
- The implementation does not generalize this pack as a generic regional visual style.
- Any cultural claim, translation, historic reference, or image attribution is verified by the responsible owner.
