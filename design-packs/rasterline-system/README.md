Rasterline is a dark, archival-operational expression system. It uses rasterized texture, explicit labels, high-contrast signal color, and numbered progression to make a complex process feel inspectable and deliberate.

It is a **Design Pack**, not an experience system. Apply it beneath a Product Binding and UX Preset; it may change character, hierarchy, density, component anatomy, and motion tone, but never remove required decision, validation, confirmation, result, or recovery meaning.

## Why this name

- **Raster** preserves the source's halftone, grid, scanline, and dithering vocabulary without tying the pack to a person or misspelled reference.
- **Line** names its linear UX: visible position, staged disclosure, explicit irreversible-action warnings, and an exit or saved-progress path.
- **System** signals that the pack covers foundation, components, and flow expression rather than a one-off art direction.

## Intended character

| Attribute | Rule |
| --- | --- |
| Voice | precise, operational, archival; concise rather than playful |
| Contrast | near-black field, warm light text, one acid signal color |
| Information hierarchy | numbered sections, mono labels, prominent operational state |
| Texture | raster texture is structural atmosphere, never a substitute for state or text |
| Shape | squared, bordered, visibly constructed surfaces |
| Motion | brief, discrete state changes; no ornamental continuous motion |

## Use when

- the product has a sequence, handoff, setup, verification, or controlled operating flow;
- users benefit from explicit current position and system status;
- an editorial/technical visual register helps establish focus.

## Do not use when

- a warm, intimate, or low-cognitive-load conversational tone is the primary product requirement;
- tiny screens cannot sustain the needed label, contrast, and target-size floor;
- texture would reduce legibility of essential data.

## Source and confidence

The Figma Make source visibly exposes 8 color tokens, a typography/spacing scale, buttons, badges, cards, inputs, progress indicators, dividers, step indicators, a four-step onboarding wizard, and texture/motion examples. Numeric values and visible component names are recorded as **observed**. Accessibility, responsive behavior, keyboard behavior, reduced motion, and production interaction have not been verified by the static source and are therefore requirements in this pack, not claimed evidence.
