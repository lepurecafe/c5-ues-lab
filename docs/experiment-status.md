# UES 실험 상태와 적용 경계

> 갱신: 2026-09-11 · 근거: 사용자의 현재 결정
> 과거 파일의 `continue`, `ready to run`, `pending`보다 이 상태 결정이 우선한다.

## Take 2 — RETIRED / 폐기

사용자 확인: “take2는 폐기된 실험 계획이야. 나중에 다른 실험을 설계해서 진행할거야.”

- Take 2는 진행·재개·출시·추가 검증 대상이 아니다.
- 관련 이름의 두 자료 묶음 모두 현재 실행 경로에서 제외한다. 서로 다른 Binding을 같다고 합치지는 않는다.
  - [배틀 중심 Take 2 기록](../experiments/design-system-value-validation-2026-08-25/take-2-random-music-app/README.md): `binding.battle-beat-randomizer@1.1.0`
  - [최소 음악 앱 투영 실험 기록](../experiments/take2-random-music-pipeline-2026-08-26/README.md): `binding.take2.random-music.minimal@0.1.0`
- 파일·코드·이미지·당시 관찰·평가는 삭제하거나 조작하지 않는다. 역사적 학습 자료로 보존한다.
- 당시 점수나 성공 사례를 현재 UES의 유효성·범용성·제품 준비도 입증으로 합산하지 않는다. 누락·수정 비용 같은 관찰은 역사적 설계 교훈으로만 인용할 수 있다.
- 당시 미완료 항목은 자동으로 현행 backlog가 되지 않는다. 재개하려면 새로운 사용자 결정과 별도 실험 계약이 필요하다.

## 다른 기록과 새 실험

COMMON SURFACE의 기존 결과는 [최신 결과표](../experiments/design-system-value-validation-2026-08-25/results/results-summary.md)에서 revision과 증거 범위별로 확인한다. 이 문서는 COMMON SURFACE의 새 실행이나 모든 기존 실험의 폐기를 선언하지 않는다.

새 실험은 **미설계 / 미착수**다. 대상·일정·참여자·매체·표본·합격 기준을 지금 지정하지 않는다. [개선안](ues-general-purpose-tool-roadmap.md)의 평가 항목은 추후 설계 시 참고할 후보이며 실행 승인이 아니다. 현재 승인된 작업은 Doctor 신뢰성 및 문서 정합성 보강이다.
