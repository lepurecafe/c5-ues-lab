# men I trust — Initial Brand Foundation

> Status: initial identity direction, 2026-08-24  
> Design Pack: `pack:90s-bmw-system@0.1.0`  
> Expression name: **Field Manual**

## Brand premise

`men I trust`는 30–40대 남성을 위한 그루밍 전문 브랜드다. 제품을 더 많이 제안하기보다 피부 상태, 면도 습관, 수면과 업무 환경을 읽고 **지속 가능한 세 단계 루틴**을 설계한다.

**Positioning:** 과장된 남성성이나 럭셔리가 아니라, 믿을 수 있는 전문성·짧은 루틴·정확한 기록.

**Core line:** `당신의 루틴을 믿을 수 있게.`

## Design translation

90s BMW System의 시각 문법을 사용하되 BMW의 자동차·상표·모델·라운델 표현은 전혀 사용하지 않는다.

| Pack grammar | men I trust translation |
| --- | --- |
| dark technical field | 네이비의 집중감, 아이보리 문서면과의 대비 |
| condensed hierarchy | 결론을 먼저 말하는 짧고 정확한 제목 |
| mono/specification logic | 루틴 번호, 사용 순서, 날짜, 제품 정보 |
| chrome rule | 브러시드 스틸, 얇은 구분선, 냉정한 물성 |
| amber warning | 한 번의 주의·리마인더·상담 우선순위 |
| instrument data | 실제 피부/루틴 정보에만 쓰는 체크와 단위 |

## Logo system

Primary mark is a lowercase wordmark: **men I trust**.

- `men`과 `trust`는 Barlow 계열의 차분한 소문자.
- 가운데 `I`는 좁은 Barlow Condensed로 잡아, “나 자신을 신뢰하는 루틴”이라는 의미를 남긴다.
- 기본 색상은 Ink on Paper 또는 Ivory on Midnight.
- 별도의 아이콘은 초기 단계에서는 강제하지 않는다. 작은 적용에서는 `mi`를 한 덩어리로 압축할 수 있으나, 외부 공개 전 상표 조사와 가독성 테스트가 필요하다.

## Voice

| Do | Avoid |
| --- | --- |
| 정확하고 짧게 설명한다 | 과장된 효능, 군대식 명령, 마초적 은유 |
| 선택 이유와 다음 행동을 남긴다 | “남자는…” 같은 일반화 |
| 상태를 이해시키고 회복 경로를 제시한다 | 공포를 이용한 문제 제기 |
