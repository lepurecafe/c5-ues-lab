## `0.2.0` 평가 전 확인 경로

사용자 평가는 독립 reviewer 판정과 별개다. 아래 경로를 직접 실행한 뒤 기존 8개 항목을 채운다.

1. 내부 preview에서 BODY filter → CS-03 → `CS03-SYN-UNKNOWN`을 만든 뒤 reload와 Back을 실행하고 맥락이 이해 가능하게 복원되는지 본다.
2. 내부 HOLD에서 malformed release audit `13/13`과 HOLD 유지가 명확한지 본다.
3. valid release를 실행한 상태에서 고객 Web이 같은 Binding revision으로 자동 바뀌는지 본다.
4. 고객 Web에서 H01의 `released/local-only`와 U01의 `unaffected synthetic fixture`가 의미상 구별되는지 본다.
5. 내부에서 HOLD를 재적용했을 때 고객 Web이 자동 복귀하는지 본다.
6. 고객 Web에서 CS-03과 unknown input을 만든 뒤 reload와 Back을 실행하고 제품·입력·disabled commit·HOLD Binding이 유지되는지 본다. 복원된 result 문구는 저장된 원문이 아니라 canonical state로 정규화될 수 있다.

### `0.2.0` 추가 관찰 메모

| 질문 | 점수에 반영할 관찰 |
| --- | --- |
| 권한 명확성 | release가 왜 거부·허용되는지 필드와 다음 행동만으로 이해되는가 |
| 두 Web 일관성 | 내부 변경이 고객 Web에 같은 의미로 도달하고, HOLD 재적용도 일치하는가 |
| 상태 구별 | released H01과 unaffected U01을 안전·판매 가능으로 오인하지 않는가 |
| 복구 신뢰 | reload·Back 뒤 사용자가 입력과 결정 지점을 잃지 않는가 |

현재 상태는 계속 **사용자 평가 대기**다. Builder `0.2.0` 자체 점수나 validator PASS를 사용자 점수로 복사하지 않으며, 독립 `0.1.1`의 `63 / 60 · STOP`도 사용자 체감 점수와 산술 혼합하지 않는다.
