## 검증 기록

- Playwright fallback 사용: 현재 제공된 Browser/IAB 제어 도구가 없어 로컬 HTTP 서버에서 Chromium으로 검증했다.
- 데스크톱: `1440×1000`, 프리뷰 전체 높이 `11042px`, 이미지 36개 로드, 오류 0.
- 모바일: `390×844`, 가로 overflow 0, 이미지 36개 로드, 오류 0.
- 상호작용: BODY 필터 결과 5개, `CS-10` 선택 후 상세 전환, 로컬 후보 선택 결과 문구를 확인했다.
- 정적 검증: 전체 아티팩트의 로컬 HTML/MD 링크 누락 0.

## 출시 준비도 6.8의 이유

9.1은 **디자인 시스템과 상업 아트디렉션 기준선**의 점수다. 실제 판매·집행에는 상표 조사, 폰트·인물·이미지 권리, INCI·용량·가격·광고 심의, 용기 엔지니어링, 도무송·bleed·컬러 프루프, 재고/상거래 API, 스크린리더·사용성 테스트가 남아 있다. 이 항목을 검증하지 않은 채 전체 제품 준비도를 9점으로 표현하지 않는다.
