# COMMON SURFACE — 브랜드 적용 기준 r1

> **상태:** 실험용 정본 기준선 · `E1`(Markdown 기준)  
> **Composition:** `composition.common-surface.r1`  
> **적용 Design Pack:** `Industrial Swiss System` / `pack:industrial-swiss@1.0.0`  
> **브랜드 아이덴티티:** [COMMON SURFACE Identity r1](common-surface-identity-r1.md)  
> **브랜드 경험 프로필:** `brand-experience.common-surface@0.1.0-experiment`  
> **Product Binding:** `binding.common-surface-starter-selection@0.1.0-experiment`  
> **UX Preset:** `decision.reserve@0.1.0` — 웹의 로컬 스타터 선택 표본에만 적용

## 1. 기준선의 목적

COMMON SURFACE는 성별 구분, 진단, 과장된 효능 언어 없이 일상적인 피부 관리의 순서를 이해하게 하는 가상의 스킨케어·머천다이즈 브랜드다. 이 문서는 패키지, 매장, 의류, 옥외, 광고, 웹에 같은 브랜드 판단을 적용하기 위한 실험 기준이다.

모든 사용자용 문장은 한글을 기본으로 한다. Pack/Preset ID, 토큰, 컴포넌트 ID, 권한 상태처럼 추적이 필요한 식별자는 원문 표기를 유지한다.

## 2. 적용한 Design Pack — Industrial Swiss System

### 2.1 선택한 이유와 적용 계약

`Industrial Swiss System`의 **따뜻하지만 단호한 실용성**을 COMMON SURFACE의 태도로 채택한다. 이는 원본 브랜드를 복제하는 뜻이 아니라, 아래의 재사용 가능한 시각 규칙을 새 브랜드에 맞게 적용한다는 뜻이다.

| Pack 계약 | COMMON SURFACE 적용 방식 |
| --- | --- |
| 12열 그리드 우선 | 웹, 라벨, 선반 카드, 포스터, 의류 그래픽의 제목·코드·행동 위치를 같은 기준선에 정렬한다. |
| 강한 정보 위계 | 한 면에는 하나의 핵심 메시지만 크게 둔다. 사용 순서·코드·제한 사항은 모노 레이블 군으로 묶는다. |
| 물성의 정직성 | 종이, 면, 금속, 유리의 질감을 구조적 단서로 쓴다. 질감이 친환경성·효능·품질의 증거가 되지는 않는다. |
| 제한된 신호색 | `--cs-signal`은 주 행동 또는 좁은 캠페인 강조에만 쓴다. 상태 의미를 색만으로 전달하지 않는다. |
| 하드 유틸리티 | 각진 모서리, 가는 테두리, 얕은 그림자, 노출된 코드와 안전 여백을 유지한다. |

### 2.2 적용하지 않는 것

- 원본 레퍼런스의 로고, 상품 이미지, SKU, 가격, 카피, 고유 그래픽 자산은 사용하지 않는다.
- 부드러운 테라피·럭셔리 미니멀·의료적 표현으로 톤을 이동시키지 않는다.
- Pack은 제품 효능, 원료, 재고, 가격, 광고 집행, 인쇄·제조 적합성을 보증하지 않는다. 그 사실은 별도 근거와 승인으로만 확정한다.

### 2.3 브랜드 고유화

Pack의 원칙은 [COMMON SURFACE Identity r1](common-surface-identity-r1.md)의 워드마크·축약 마크·언어 규칙을 통해 제품과 매체에 적용한다. 워드마크는 Pack의 원본 표식이 아닌 가상 실험 자산이며, Pack은 그 자산의 위계·정렬·물성·신호색 사용 규칙만 제공한다.

## 3. 권한과 콘텐츠 원칙

| 상태 | r1에서의 사용 |
| --- | --- |
| `experiment-approved-synthetic` | COMMON SURFACE 이름, 제품 코드, 작업명, 이 토큰 세트, 레이아웃·컴포넌트 규칙 |
| `unresolved` | 처방, 성분, 효능, SPF/PA, 용량, 가격, 재고, 모델·이미지 권리, 제조, 인쇄, 매장·광고 집행 사실 |
| `externally-authorized` | r1 기준선에는 없음 |
| `prohibited` | 레퍼런스 브랜드 표식·제품 이미지·SKU·가격, 성별 고정관념, 진단, 검증되지 않은 주장 |

## 4. 시각 토큰과 구성

| 역할 | 토큰 | 값 또는 규칙 |
| --- | --- | --- |
| 읽기 바탕 | `--cs-paper` | `#F3EFE7` |
| 주 잉크 | `--cs-ink` | `#1A1713` |
| 보조 잉크 | `--cs-stone` | `#746D63` |
| 구분선 | `--cs-line` | `#B9B0A3` |
| 주 행동 | `--cs-signal` | `#C7382C`; 텍스트·아이콘을 반드시 함께 쓴다. |
| 제한된 강조 | `--cs-field-blue` | `#315B78`; 캠페인·물성 강조에만 사용한다. |
| 포커스 | `--color-focus` | `--cs-signal` 외곽선; 구현 시 대비를 측정한다. |

- 제목은 응축형 고대비 계열, 본문은 평이한 문장, 코드·날짜·단위·권한 표시는 모노 계열을 쓴다.
- 한국어는 강제 대문자화하지 않는다. 실제 폰트와 CJK 폴백은 라이선스·구현 단계에서 확정한다.
- 데스크톱은 12열과 24px 거터를 기준으로 하며, 모든 매체는 같은 정보 우선순위를 축소·재배치한다.

### 5.2 재사용 컴포넌트

| 컴포넌트 | 필수 내용 | 매체 규칙 |
| --- | --- | --- |
| 제품 코드 락업 | 코드, 작업명, 권한 상태 | 제목과 모노 레이블을 짝지우며, 사실 정보를 대신하지 않는다. |

| 권한 스트립 | 사실·주장 레이블, 상태, 근거 공백 | 설득 문구보다 먼저 보이게 한다. |
| 패키지 정보 블록 | 정체성, 용량·사용법·필수 표시용 자리 | 가짜 법정 문구를 쓰지 않고 안전 여백을 남긴다. |
| 캠페인 락업 | `COMMON SURFACE / 일상의 피부 관리` | 한 메시지와 읽을 수 있는 다음 행동만 둔다. |

## 6. 브랜드 경험과 Product Binding

| 접점 | r1 동작 원칙 |
| --- | --- |
| 패키지·선반 | 정체성, 루틴 역할, 권한 상태를 홍보 언어보다 먼저 제시한다. |
| 매장·테스터 | 위생·재고 문제를 차분히 밝히고, 맥락을 잃지 않는 대체 경로를 제공한다. |
| OOH·광고 | 검증 가능한 하나의 제안과 목적지만 둔다. 구매·효능을 가장하지 않는다. |
| 웹 선택 | 시스템 제안, 사용자 초안, 로컬 저장, 확인 결과를 서로 구분한다. |
| 지원·반품 | 아는 사실·미확정 사실·다음 행동을 비난 없이 명시한다. |

대표 흐름은 **구매가 아닌 로컬 스타터 제품 선택**이다.

```text
제품 탐색 → 후보와 근거·한계 확인 → 선택 또는 교체
→ 실험용 필수 사실 확인 → “스타터로 저장” 로컬 확정
→ 로컬 선택 완료 + 수정 / 초기화 / 도움
```

`default`, `focus-visible`, `invalid`, `loading`, `success`, `unavailable`, `alternative` 상태가 필요하다. 사실이 비어 있거나 후보를 사용할 수 없으면 저장을 막되, 기존 입력·선택 맥락은 보존한다.

시각 검토물은 [아이덴티티 r1](common-surface-identity-r1.md), [매체별 r1 투영본](common-surface-r1-projections.html), [웹 상호작용 프리뷰](preview.html), 생성 이미지 [제품 정물](assets/common-surface-product-still-r1.png)·[매장](assets/common-surface-retail-r1.png)·[캠페인](assets/common-surface-campaign-r1.png)·[머천다이즈](assets/common-surface-merch-r1.png)이다. 이미지는 이 실험을 위해 생성한 아트디렉션용 시안이며, 실제 광고·패키지·제조·인쇄·접근성 런타임·상거래의 증거는 아니다.

이 기준선의 산출물 범위와 평가 전 동결 상태는 [r1 완료 매니페스트](common-surface-r1-completion-manifest.md)에 기록한다.

## 8. 다음 검증 전 남은 공백

- 렌더된 매체별 실물, 명도 대비 측정, 키보드 경로, 이미지 라이선스, 물성 샘플은 아직 검증되지 않았다.
- 시장별 표시 요건, 성분·효능 근거, 재고·구매 데이터도 없다.
- r2는 통제된 `OUTSIDE / 01` 변경만 추가할 수 있다. 그 외 변경은 새 Change Request가 필요하다.
